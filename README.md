# About Swag

Swag is a next-generation short video platform focused on simplicity, performance, premium design, and creator experience.

Unlike traditional short-video apps, Swag is built around a unique experience:

• Create Reels
• Sing with Music
• Creator Monetization
• Subscription System

The goal is not to copy existing platforms.

The goal is to build a cleaner and better experience.
